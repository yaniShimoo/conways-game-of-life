# 3. Conway's Game of Life Algorithm

Implement Conway's original Game of Life cellular automaton.

The simulation operates on a two-dimensional grid.

Each cell has two possible states:

- Alive
- Dead

Each cell interacts with its eight neighboring cells.

Implement the four original rules:

1. A living cell with fewer than two living neighbors dies due to underpopulation.
2. A living cell with two or three living neighbors survives.
3. A living cell with more than three living neighbors dies due to overpopulation.
4. A dead cell with exactly three living neighbors becomes alive through reproduction.

### Critical Requirements

All cells must update simultaneously.

Calculate each generation using a separate data structure.

Do not modify the current generation while computing the next generation.

Use finite grid boundaries.

Cells outside the grid are considered dead.

Do not implement wrapping or toroidal boundaries.

The algorithm must produce mathematically correct results.

When pressed:

- Stop the simulation.

- Reset the generation counter to zero.

- Restore the initial empty grid.

## 5.4 Step Forward

Implement a Step button.

When pressed:

- Calculate exactly one new generation.
- Update the grid.
- Increase the generation counter by one.
- Update the population counter.
- Keep the simulation paused.

## 5.5 Randomize

Implement a Randomize button.

When pressed:

- Stop the simulation.
- Generate a random configuration of living cells.
- Use a reasonable initial population density.
- Reset the generation counter to zero.
- Update the population counter.
- Display the new configuration immediately.

## 5.6 Speed Control

- Allow the user to adjust the speed at any time.
- Apply changes immediately.
